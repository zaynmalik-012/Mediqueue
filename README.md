## 🏥 About The Project

**MediQueue** is a lightweight, responsive web application designed to eliminate overcrowded waiting rooms and unpredictable delays in hospital Outpatient Departments (OPD). 

Instead of waiting in congested hospital corridors, patients can register, book digital tokens with dedicated **20-minute consultation windows**, and track live queue progress from anywhere. 

### ⚡ Key Highlights
* **Predictive Wait Times:** Accurately estimates consultation delays using live queue math:
  $$\text{Estimated Waiting Time} = \text{Patients Ahead} \times \text{Doctor's Consultation Pace}$$
* **Dynamic Slot Locking:** Automatically removes booked 20-minute time slots to prevent double-booking for the same doctor and date.
* **Dedicated Doctor Desks:** Individual credential-based portals for each hospital specialist to call the next patient, advance tokens, and adjust queue waiting times hospital-wide.
* **Casualty & Emergency Guard:** High-visibility safety protocols and direct emergency physician hotlines ensuring acute, critical cases bypass OPD queues for immediate 24/7 trauma care.
